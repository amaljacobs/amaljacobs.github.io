# Amal Jacob Personal Site

A starter personal site built with Astro and React.

## Tech Stack

- Astro
- React
- CSS

## Development

Install dependencies:

```sh
npm install
```

Start the local dev server:

```sh
npm run dev
```

Build for production:

```sh
npm run build
```

Preview the production build:

```sh
npm run preview
```

## Deployment

This project is static and can be deployed to GitHub Pages, Netlify, or Vercel.
